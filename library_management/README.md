# library_management

Library Management — Application Flutter pour la gestion d'une bibliothèque.

## Installation

Prérequis:

- Flutter SDK
- Avoir un éditeur (VS Code, Android Studio)

Installation rapide:

```bash
flutter pub get
flutter run
```

## Structure

- `lib/`: code Dart principale
- `android/`, `ios/`, `web/`, `windows/`, `linux/`, `macos/`: plateformes
- `test/`: tests
